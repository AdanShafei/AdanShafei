## Featured Projects

### 🛰️ [Semi-Supervised Image Segmentation](https://github.com/AdanShafei/semi-supervised-image-segmentation)
Satellite image segmentation with limited labelled data, using a ResNet-18 encoder–decoder and pseudo-labelling.
- Raised mIoU from **0.37 to 0.46** by retraining on high-confidence pseudo-labels and adding test-time augmentation
- Four-stage training schedule with Dice + BCE loss, AdamW, and plateau-based learning-rate scheduling

`ResNet-18 · Computer Vision · Semi-Supervised Learning`

---

### 🌦️ [Drought Severity Predictor](https://github.com/AdanShafei/drought-severity-predictor)
Classifies weekly drought severity (D0–D3) from 15 years of California climate and soil-moisture data.
- Ensembled a neural network with XGBoost, handling heavy class imbalance
- Reached **85% balanced accuracy** and **80% ensemble test accuracy**

`Python · TensorFlow/Keras · XGBoost · Feature Engineering · Imbalanced Data`

---

### 🤖 [Pac-Man Multi-Agent AI](https://github.com/AdanShafei/pacman-capture-the-flag-ai)
Two-agent adversarial system with real-time decision-making for competitive Capture the Flag.
- Offensive agent balances food collection, risk assessment, and safe returns
- Defensive agent uses threat-based heuristics to prioritise invader interception
- Scored **9/10** against baseline agents

`Python · Multi-Agent Systems · Heuristic Evaluation · AI`
